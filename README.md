
これは、外部操作を止める設定ファイルの一部（19行）を、5行は一般名に替えて置いた見本です。

解説どおりにやっても自分の環境では動かず、何度もやり直してやっと動く──という人向けです。動かない解説ではなく、実際に動いている設定を置きます。

使い方
①この19行を、自分の設定ファイルの deny（止める側の一覧）に足す
②自分の主要な設定ファイルの行数を一度数えて、19という数と比べる
③実際にその操作を打って、拒否されるか動かして確かめる

注意：これは Claude Code という道具の permissions（許可の設定）の deny（拒否）の形です。この設定が事故を必ず止めるとは書きません。
